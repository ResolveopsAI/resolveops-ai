# Multi-Channel Alerting Documentation

## Overview
Dispatches operational alerts generated by backend threshold events to Slack, Microsoft Teams, and PagerDuty.

## Supported Channels
1. **Slack**: Incoming webhook integration.
2. **Microsoft Teams**: Workflow / Webhook message cards.
3. **PagerDuty**: Events API v2 for `CRITICAL` & `ERROR` events.

## Configuration
```env
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...
TEAMS_WEBHOOK_URL=https://outlook.office.com/webhook/...
PAGERDUTY_ROUTING_KEY=pd-key-12345
ALERT_COOLDOWN_MINUTES=15
```
